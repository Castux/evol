evol 2.0
========

With the advent of SDL 2, evol needs an overhaul. With evol 2.0 we want to take advantage of the SDL 2's new or improved features:

- cross platform: Linux, Mac OS X, Windows, and Ouya
- keyboard/mouse and gamepad input
- hardware accelerated 2D graphics (images, primitives, text)
- better unicode support

We still want evol to be a minimal wrapper around low level stuff, with all the more advanced "engine" done in higher level languages. To that extent, evol 2.0 should present a C interface, and an independent Lua wrapper. That way it could be used in C++, D, or whatever else.

We also decide to drop the "open OpenGL context" thing and the emulated curses from previous verions, are they become irrelevant (OpenGL is not trivially portable to Ouya, which uses GLES, and fake curses can be done at higher level).

evol is still built as a Lua module, that can be loaded from the standard 5.1 interpreter, but provides a minimal loader if you need to compile it yourself.

Video
=====

We assume that we'll always have a single non resizable window.

evol.init()
evol.quit()

w,h = evol.get_native_size()
(if you need to know before you decide of a mode. This gives the size of the display where the window is currently.)

evol.set_mode(mode,[w,h])
mode: "windowed","fullscreen". Full screen is the new "desktop fullscreen" that does not switch the native size
w,h: size, optional (0x0 in C for optional). If not provided, a reasonable size is chosen (highest available mode in fullscreen, second highest in windowed). If provided in windowed, you get the required size, and in fullscreen you get a "virtual" screen fitted to native fullscreen size.

mode,w,h = evol.get_mode()
evol.width
evol.height
in windowed mode, simply the window size. In fullscreen mode, returns the virtual size (if it's set), or the native size (if virtual hasn't been set).

evol.set_scaling_quality(quality)
quality: "nearest", "linear"

dt,fps,t = evol.update_timer([fpsmax])
(unchanged, but now all in seconds)

evol.update_screen()

Graphics
========

image = evol.load_image(path)
evol.free_image(image)
image: an opaque userdata with a texture loaded from an image

evol.draw_image(image,x,y)
evol.draw_image(image,x,y,scale_x,scale_y,pivot_x,pivot_y,angle)
Image's pivot is given in the original image's coordinates. That is: rotation and scaling is applied around pivot, and the pivot always ends up in the given (x,y) coordinates. Scaling can be negative. Angle in degrees, clockwise positive (y axis does down).

Display tree
============

All in Lua, a function evol.update_transform_tree(t) takes a node, computes tranforms, and draws whatever it finds:

node = {
	scale = 1,		-- if present, applies to current transform
	angle = 0,		-- if present, applies to current transform
	x = 0,			-- etc.
	y = 0,			-- etc.

	visible = true,

	children = {}	-- if present, calls recursively on them
	children_lists = {}		-- calls recursively on the content of these lists

	scale_x = 1,	-- anisotropic scaling (applied only to this node's texture and/or vector graphics)
	scale_y = 1,	-- etc.
	texture = Texture() -- if present, draw texture at current tranform
	graphics = Graphics()	-- if present, draws vector graphics at current transform
}

On the way, it fills in global_scale, global_angle, global_x and global_y for each node. For optimization (later), maybe a no_update flag
